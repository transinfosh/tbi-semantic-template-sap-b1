# 库存语义BDD场景

## INV-01

- Given 两个物料使用相同SysNumber且位于不同仓库。
- When 查序列号余额。
- Then 使用OSRQ自身唯一组合和MdAbsEntry，不按SysNumber合并，不当作期间交易。

## INV-02

- Given 申请已关闭但未调拨，另一笔调拨源和目标仓不同。
- When 查库存移动。
- Then 申请与执行分开，源/目标仓分角色，不用申请状态推实际移动。

## INV-03

- Given 同来源行有多日志/估价层且金额部分缺失或数量为零。
- When 查估价金额。
- Then 先聚合并保留来源键，不补已确认零，不从零数量反推单价。

## INV-04

- Given 物料和资源内部编码、描述超过旧模型长度。
- When 保存语义模型。
- Then 只扩容语义元数据，原键、源数据和旧发布保持。
