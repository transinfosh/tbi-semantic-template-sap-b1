# 采购、生产、库存与财务语义复核

日期：2026-10-22。本轮沿用已确认的销售整理标准：默认模型按常用业务问题取舍，保留历史事实、稳定键、日期状态与完整币种金额；共享维度归主数据，低频/地区化功能不因物理表存在而整族纳入。研究、实施、技术验证和业务金额验收分层记录。

## 已实现的本地候选

公共模板0.8.0共101模型、3091字段、370关系。相对0.7.1新增488列、移除77列、更新94列元数据（含17个源库已非空的主键标记），增加95条关系；原有275条关系和20张销售模型保持。字段级动作见[选择清单](cross-module-field-selection.json)。新增表仅PCH3、RPC3、OSRQ。

| 模块 | 本轮优化 | 保留的边界 |
| --- | --- | --- |
| 采购 | 完整核查20个已有模型；补采购费用PCH3/RPC3，保存的税/折扣/费用/舍入三币、服务未清、历史描述、交期、项目与责任维度，补抵扣附表金额配套；修采购申请归属/币种、预留应付发票说明和编码长度；删不适用的收付/毛利/记账字段 | OPRQ/PRQ1已是采购申请，OPRR/PRR1是既有实例采购退货请求。请求、实际退货、贷项和库存移动分开。Landed Costs、分期、地区化与多角色分配查询仍需专项 |
| 生产 | 产品/组件名称、仓库/单位/项目、开始/下达日期、附加量、在制品科目与分配规则；补BOM资源及明确维度关系；数据库完成/拒收改为C/R，不能用SDK的0/1；资源编码/描述兼容扩容 | 当前BOM或资源成本不覆盖历史工单；材料发料估价不等于最终工单成本。工序、产能、资源退回和其他估价来源待专项 |
| 库存 | 补OSRQ当前序列仓库数量及主记录关系，补日志动作/累计/位置类型与项目，区分调拨申请和实际执行，兼容物料码50字符；精简共享收款/毛利/申请估价字段 | OITW/OBTQ/OSRQ是当前余额，不能自动回溯历史；库位余额/盘点/期初不默认扩表。第二仓库角色、无类型批序列关联和未审估价来源不放行 |
| 财务 | 收付款方式与挂账三币、转账事实、资金科目编码，应用行费用/舍入和核销费用三币；修金额精度、科目名称长度、币种职责和类别说明；US1099 PaidSum退出默认精选 | 支付父子关系、资金科目角色别名、分录BP双义仍有待审边界；历史账龄、现金流、预算/固定资产与完整财务对账不因此宣称已完成 |

实例已有的采购退货请求另按官方职责整理：保留“不作数量过账”为后续流程选择，不按共享I/S枚举宣称支持服务退货请求；实例扩展不自动加入公共模板。五维分配规则保留保存编码，多个同目标角色名称需查询验证后采用；未修改通用Agent、运行协议、权限或SAP源库。

## 兼容和证据

删除列改变后续草稿可选择字段，须先执行原生依赖检查；不删除SAP物理列、不改既有技术名/键/既有关系，也不重写图表历史和冻结发布。字符串扩容只是语义元数据，目标列已由只读系统元数据核对；没有schema迁移。模板源码更新不表示远端Git或其他实例已同步；草稿保存不自动发布。
