# 模板类型 BDD 场景

## TTYPE-01 基础类型与来源参数分离

- Given 公共模板和可选扩展的字段原有带参数或不带参数的类型。
- When 将类型标注统一为基础类型并导出 MDL。
- Then 每列只保留大写基础类型；原始标注逐列留在校验资料，已有长度和精度可完整读取，原先未知的参数不补猜；校验资料不进入 MDL，键、说明、顺序及关系保持。

## TTYPE-02 拒绝类型漂移

- Given 已有列的来源类型记录为 `DECIMAL(19,6)` 或 `VARCHAR(200)`。
- When 类型重新带参数、使用小写/未知类型、基础类型与来源不一致，或来源记录缺失/格式错误。
- Then 构建明确报错并定位列，不静默修改输入，不生成有误的 MDL。

## TTYPE-03 SQL 与 CAST 保持

- Given SQL 包含 `CAST(... AS DECIMAL(19,6))` 或 `CAST(... AS VARCHAR(100))`，以及字符串中的类型文字。
- When 仅规范化字段 `type` 并构建。
- Then SQL 内容逐字保持，参数不被截断，数值/文本转换不改写；现有工作区 View SQL 全部保持。

## TTYPE-04 重复构建与兼容

- Given 规范化后的公共模板及英文可选扩展。
- When 重复构建、选择语言和执行既有回归。
- Then 输出确定，源文件不变；类型属于当前 tBI 类型目录，按现有规范化规则与修订前等价。既有 PaidSum 来源精度、两族区别及 LeadTime 规则保持；不导入工作区或修改发布。
