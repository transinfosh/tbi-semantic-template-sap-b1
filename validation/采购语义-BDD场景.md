# 采购语义BDD场景

## PUR-01

- Given 同一订单部分收货和开票，另有同键不同来源类型。
- When 分析采购履约。
- Then 匹配来源三键；各分支先聚合，不重复累计头金额。

## PUR-02

- Given 服务行没有物料编码，有历史描述、未清金额和三币保存值。
- When 分析服务采购金额。
- Then 保留服务及未匹配行；按币种读取保存金额，不用当前税组或汇率重算。

## PUR-03

- Given 发票和贷项有同类型多条费用及未匹配类型。
- When 分析费用组成。
- Then 保留费用记录键、原始方向和币种；不按费用编码去重，不重复计入头总额。

## PUR-04

- Given 申请和退货请求均存在且后者为实例扩展。
- When 整理模型。
- Then 不混淆对象，不自动推广实例扩展，不把请求标志当实物移动；删字段前检查依赖。

## PUR-05 字段覆盖与双语定义

- Given 公共模板已有应付发票头、累计收付族及物料提前期。
- When 构建模板并选择中文或英文。
- Then 三个 PaidSum 族字段各出现一次，保持标准大小写、物理列和头粒度；语义类型为 DECIMAL，来源资料保留 19,6 精度；两种语言均区分币种和待核验边界；PaidToDate 族保持独立；LeadTime 不重复、不改名，单位仍为天。

## PUR-06 差异、空值与状态核对

- Given 两族保存值有相等、不等、零、负数及空值样本，并包含未取消未手工关闭、手工关闭、取消及取消单据。
- When 执行只读核对 SQL。
- Then 每张发票仅输出一次，三币各自比较，任一侧为空时结果标为未知且差值为空；零与负值原样保留；不以状态过滤差异，不产生未清余额或付清判定，不以另一族补值。

## PUR-07 SAP 更新与结算组成（真实业务待验收）

- Given 可丢弃 SAP 公司库有本币/外币发票，且本币与系统币不同。
- When 分别进行部分/多次/分期付款、撤销付款、贷项/预付款抵扣、内部核销及撤销、折扣/预提税/汇差/舍入、手工关闭和取消。
- Then 逐事件记录两族三币保存值、币种设置、凭证及核销证据，与 SAP 报表核对；明确实际更新行为和差异来源后才形成专项口径。缺证据时保持待核验，不能假定两族相等、未清公式或历史余额。

## PUR-08 发布隔离与兼容

- Given 既有工作区有自己的模型、View/Cube、图表、仪表板及发布版本。
- When 仅修改和离线验证公共模板。
- Then 原有键和关系保持，新增三列可供后续预览；不访问线上工作区、不触发导入或发布、不改变既有资产。0.8.0 删除记录通过后续恢复动作补充说明。
