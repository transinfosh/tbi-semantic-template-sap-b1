# 采购语义BDD场景

## PUR-01

- Given 同一订单部分收货和开票，另有同键不同来源类型。
- When 分析采购履约。
- Then 匹配来源三键；各分支先聚合，不重复累计头金额。

## PUR-02

- Given 服务行没有物料编码，有历史描述、未清金额和三币保存值。
- When 分析服务采购金额。
- Then 保留服务及未匹配行；按币种读取保存金额，不用当前税组或汇率重算。

## PUR-03

- Given 发票和贷项有同类型多条费用及未匹配类型。
- When 分析费用组成。
- Then 保留费用记录键、原始方向和币种；不按费用编码去重，不重复计入头总额。

## PUR-04

- Given 申请和退货请求均存在且后者为实例扩展。
- When 整理模型。
- Then 不混淆对象，不自动推广实例扩展，不把请求标志当实物移动；删字段前检查依赖。
