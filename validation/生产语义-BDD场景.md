# 生产语义BDD场景

## PROD-01

- Given 相同组件编码可为物料、资源或文本，资源显示码不同于内部码。
- When 读取组件信息。
- Then 按Type/ItemType判别，资源用ResCode；未知/文本不错误连接物料。

## PROD-02

- Given 工单产品与重复组件行使用不同仓库、项目。
- When 按组件分析。
- Then 保留行键、本行仓库和项目，不以头值覆盖，不按编码去重。

## PROD-03

- Given 收货有C/R和其他来源角色，调用方也知道SDK数值枚举。
- When 分析完成/拒收。
- Then 数据库使用C/R；不使用0/1过滤，也不把所有收货当最终产品。

## PROD-04

- Given 发料有多估价交易和层，包含NULL、负数或零数量。
- When 分析发料估价。
- Then 保留已审分层聚合、NULL、符号和无单价语义，不宣称已获最终成本。
