# 销售语义测试映射

日期：2026-10-20。对应[规格契约](销售语义-规格契约.md)及[BDD 场景](销售语义-BDD场景.md)。本轮为 `0.4.0` 销售模块整理；历史 `cases.json/results.json` 不自动证明本轮销售业务验收通过。

## 1. 证据等级

| 级别 | 能证明 | 不能证明 |
| --- | --- | --- |
| 官方来源 | 字段、类型、枚举及业务角色有依据，明确组合解释与待核项 | 所有目标版本和地区均已兼容 |
| 模板结构 | 关键字段组齐全、类型族合理、引用有效、构建可复现 | 真实金额正确或 Agent 会选对字段 |
| 自造数据 | 实际模板连接条件在给定多行、分支、错类型样例下的结果 | 所有地区化及真实异常已覆盖 |
| 目标兼容/发布 | 指定实例的物理列、引擎、导入合并与激活状态 | 与 SAP 业务报表金额已经对账 |
| 真实业务/问答 | 指定范围、冻结版本和真实调用下的结果 | 未覆盖范围也通过 |

字符串存在检查归为内容传递验证。来源说明、结构测试与自造样例不能替代真实问答。客户数据、连接和发布身份只保留在使用方私有记录中。

## 3. 本轮执行记录

- 官方核对：七头七行新增121个字段逐一核对拼写、类型和精度，14个官方表页面的哈希随来源记录保存。已有字段的技术名、类型、主键及非说明属性保持；`Dpm*` 待核实边界未改写为确认。

- 自动化：2026-10-20 执行构建校验与全套40项测试均通过，其中销售专项10项；销售测试文件的Ruff E9/F/I检查通过。
- 目标兼容、隔离导入及发布：由使用方私有记录维护，本文件不包含实例标识或客户数据。
- 业务金额与SAP报表核对、真实Agent问答：未执行。预付款FC来源、特殊来源边、复杂税费/单位、取消与贷项范围仍按规格逐项验收。
