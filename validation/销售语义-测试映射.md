## 1. 证据等级与记录规则

| 级别 | 能证明的内容 | 不能据此宣称 |
| --- | --- | --- |
| 官方来源核实 | 字段定义、币种来源和适用范围有依据；明确仍待核实项 | 所有目标公司库或历史单据已兼容 |
| 模板及结构测试 | 文件可构建、已有名称与关系保持、说明内容与已确认契约一致 | 真实数据金额正确，或 Agent 已理解说明 |
| 自造数据验证 | 给定样例下的币种分组、粒度、方向和重复计量边界 | 覆盖所有本地化、单据类型和真实业务异常 |
| 目标数据验证 | 指定目标版本、公司配置、范围与样本的实际金额核对 | 未覆盖范围已验收，或真实 Agent 会自主选对字段 |
| 真实问答验收 | 指定模型、冻结语义、真实工具调用与样本下的问答表现 | 所有模型和所有业务问题都已通过 |

仅检查某句说明或字段名是否出现，归为模板内容检查。模型调用与业务行为需要单独证据，不得因断言通过将以下场景批量标为已验收。
