# 财务凭证分录行日期修补

日期：2026-10-22。范围仅限 `finance_journal_line_detail`，对应审查 R02 / SF-01。已更新源码及 P1 草稿，未发布。

## 实现与兼容

- 既有 `posting_date / document_date / due_date` 继续读取 OJDT.RefDate/TaxDate/DueDate，显示名明确为“凭证头过账日期／单据日期／到期日期”。
- 追加 `line_posting_date / line_document_date / line_due_date`，分别读取 JDT1.RefDate/TaxDate/DueDate；原始空值不以头日期回填。
- 原 21 列的技术名、顺序、表达式、数量及金额口径保持，新增三列在输出末尾。此 View 现在 24 列，P1 的 16 个 View 合计 323 列。
- View 说明区分头日期与行日期查询用途，不自动选择财务归期，不把此 View 扩展为历史账龄算法。

SAP 正常业务允许在相应设置下单独编辑分录行过账日期，依据 [单据设置官方帮助](https://help.sap.com/docs/SAP_BUSINESS_ONE/68a2e87fb29941b5bf959a184d9c6727/45071a63f61941dee10000000a1553f6.html)；头行字段映射据 [官方日记账导入字段说明](https://help.sap.com/docs/SAP_BUSINESS_ONE_WEB_CLIENT/2554bf7e9aa347729b0547a737e123ac/39de79e28e17476cba4da8a30d72292a.html)。合成测试使用这种合法配置下的日期差异，不人为删除工单或其他所属业务记录。
